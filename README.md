# 📝 Daily Task Reminder  

A sleek and efficient web application designed to help users manage their daily tasks effortlessly. With its user-friendly interface, the app allows users to add, view, and delete tasks, ensuring productivity and organization in a minimalistic design.

## ✨ Features  
- **Add Tasks**: Quickly add tasks with a single click.  
- **Delete Tasks**: Remove tasks once completed.  
- **Responsive Design**: Adapts seamlessly to both desktop and mobile devices.  
- **Modern Aesthetic**: Styled with a clean and professional look using a contemporary color palette.  

## 🛠️ Technologies Used  
- **HTML5**: For structuring content.  
- **CSS3**: For styling and layout.  
- **JavaScript**: Handles task management logic.  
- **Google Fonts**: Enhances the app’s typography.  

## 🚀 Setup and Installation  
1. **Clone the Repository**:  
   ```bash  
   git clone https://github.com/RahgulKrishna/Daily-Task-Reminder.git  
   ```  
2. **Navigate to the Project Directory**:  
   ```bash  
   cd Daily-Task-Reminder  
   ```  
3. **Open `index.html` in Your Browser**:  
   Double-click on `index.html` or use a local server for a better experience.  

## 💡 Usage  
1. **Adding a Task**:  
   - Type a task in the input field.  
   - Click the **"Add Task"** button to save it.  

2. **Viewing Tasks**:  
   - Added tasks will appear in a list below the input field.  
   - Each task is displayed with a delete button for easy management.  

3. **Deleting a Task**:  
   - Click the delete button next to a task to remove it from the list.
